## 14. Naming Conventions

- Use lowercase kebab-case for topic folders (`union-find`, not `UnionFind`).
- Keep numbered prefixes (`01-`, `02-`) only for the eight stage folders of this domain.
- Use snake_case for Python files and modules (`binary_search.py`).
- Name tests `test_<topic>.py` and property tests `test_<topic>_properties.py`.
- Every folder that a learner is meant to open has its own `README.md`.
